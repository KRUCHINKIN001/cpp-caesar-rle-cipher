# Шифрование и сжатие числового текста

Учебная консольная программа на C++, которая шифрует строку
из цифр шифром Цезаря, а затем сжимает её алгоритмом RLE.

Также реализовано обратное преобразование и сравнение
восстановленной строки с исходной.

## Возможности

- Ввод строки длиной от 1 до 100 символов.
- Проверка ввода: разрешены только цифры от 0 до 9.
- Шифрование с постоянным ключом 3.
- Сжатие последовательностей одинаковых цифр.
- Восстановление зашифрованной строки из RLE.
- Расшифровка и проверка совпадения с исходной строкой.

## Как работает шифрование

Каждая цифра сдвигается на три позиции вперёд.
После цифры 9 отсчёт продолжается с 0.

Примеры:

- 0 → 3;
- 1 → 4;
- 7 → 0;
- 9 → 2.

Формула шифрования:

```cpp
(digit + 3) % 10
```

Формула расшифровки:

```cpp
(digit + 10 - 3) % 10
```

## Как работает RLE

Каждая группа одинаковых цифр заменяется цифрой
и количеством её повторений.

Например:

```text
4444 → 44
555 → 53
22 → 22
```

Программа выводит два варианта:

1. Без разделителей — для основного задания.
2. С разделителями — для однозначного восстановления.

Пример:

```text
Зашифрованная строка: 4444555566662222
Сжатая строка: 44546424
RLE с разделителями: 44;54;64;24;
```

В записи `44;` первая цифра обозначает символ,
а оставшаяся часть до точки с запятой — количество повторений.

Например, `410;` означает десять повторений цифры 4.

Разделители нужны, потому что количество повторений
может состоять из нескольких цифр.

## Обратное преобразование

Обратные действия выполняются в следующем порядке:

1. Восстановление зашифрованного текста из RLE с разделителями.
2. Расшифровка с ключом 3.
3. Сравнение результата с первоначальным текстом.

Функция восстановления получает RLE, созданное самой программой.
Ввод произвольной RLE-строки пользователем не предусмотрен.

## Сборка и запуск

### В Code::Blocks на Windows

1. Создайте консольный проект C++.
2. Добавьте исходный код в main.cpp.
3. Используйте стандарт C++11 или новее.
4. Сохраните main.cpp в кодировке Windows-1251.
5. Выполните сборку и запуск.

В программе используются функции Windows:

```cpp
SetConsoleOutputCP(1251);
SetConsoleCP(1251);
```

Они согласованы с выбранной кодировкой исходного файла.

### Через g++ в Windows

Пример сборки в режиме C++17 с кодировкой Windows-1251:

```bash
g++ -std=c++17 -Wall -Wextra -finput-charset=CP1251 -fexec-charset=CP1251 main.cpp -o program.exe
```

Запуск в PowerShell:

```powershell
.\program.exe
```

## Пример работы

Ввод:

```text
1111222233339999
```

Вывод:

```text
Исходная строка: 1111222233339999
Зашифрованная строка: 4444555566662222
Сжатая строка: 44546424
RLE с разделителями: 44;54;64;24;

После восстановления RLE: 4444555566662222
После расшифровки: 1111222233339999
Проверка: строки совпадают.
```

В примере из условия есть неточность: результат
`3333444455551111` соответствует ключу 2.
В программе используется требуемый ключ 3.

## Проверка работы

| Вход | После шифрования | RLE без разделителей |
|---|---|---|
| 0 | 3 | 31 |
| 9999 | 2222 | 24 |
| 11122 | 44455 | 4352 |
| 0123456789 | 3456789012 | 31415161718191011121 |

Дополнительные проверки:

- Пустая строка — сообщение об ошибке.
- Строка с буквами — сообщение об ошибке.
- Строка с пробелами — сообщение об ошибке.
- Более 100 символов — сообщение об ошибке.
- 100 одинаковых цифр — корректное сжатие и восстановление.

## Функции программы

- checkText — проверяет длину и символы строки.
- encrypt — шифрует цифры.
- compressRLE — создаёт два варианта RLE.
- restoreRLE — восстанавливает зашифрованную строку.
- decrypt — расшифровывает цифры.
- main — организует ввод, преобразования и вывод.
